# Contributor guides

Start with [CONTRIBUTING.md](../../CONTRIBUTING.md) for the workflow; these guides go into detail.

- [Add a new source](add_new_source.md): a law, decision or guidance text, from the official portal
  to the Turtle.
- [Annotated XML](annotated_xml.md): official XML with annotations added, or XML transcribed from
  HTML and PDF, and how its text is compared.
- [Annotations](annotations.md): the `lga:` attributes that say what each provision does.
- [Language versions, consolidated texts and their proof](eu_law_language_versions.md): parallel
  language versions, consolidated EU texts, amendments and corrigenda.
- [Licences and link-only sources](licences_and_link_only.md): what may be kept here, and how other
  people's work is linked instead.
- [Add a court or authority decision](add_court_or_authority_decision.md): the decision as a
  source, and its case number, outcomes and rules.
- [Translations](../translations.md): English for every non-English text.
