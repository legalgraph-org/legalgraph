# Law texts

Official texts exactly as their portals publish them, one directory per source
(`sources/<country>/<act>/`), each with its `source.yaml` index and the annotated XML the graph is
extracted from. `link-only.yaml` lists other people's work that is linked, not kept.

How to add or update a source: [docs/contribution/add_new_source.md](../docs/contribution/add_new_source.md).
